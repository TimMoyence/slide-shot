Un composant manque à l'appel

Slide Shot a besoin de poppler pour lire les PDF et fabriquer les images. Ce composant n'est pas installé sur cet ordinateur.

Pour l'installer :

  1. Ouvrez l'application Terminal.
  2. Placez-vous dans le dossier du projet (glissez le dossier sur la fenêtre du Terminal, ou tapez cd suivi d'un espace puis glissez le dossier).
  3. Tapez la commande suivante puis appuyez sur Entrée :
npm run setup

Si cette commande échoue, essayez :

brew install poppler

Une fois l'installation terminée, revenez ici et cliquez sur « Réessayer ».
